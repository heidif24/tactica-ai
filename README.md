# ✦ Lumen

**Light on your data.**

Complete analysis product for Vercel:

- Marketing homepage
- Pricing (Free + Pro $9/mo)
- Analysis workspace (upload CSV → checklist → clean → results + charts)
- Freemium: 3 free analyses / month; Pro unlock (demo; Stripe-ready)

## Local

```bash
npm install
npm run dev
```

## Deploy on Vercel

Import the GitHub repo → Framework Next.js → Deploy.

No env vars required for the free demo.
